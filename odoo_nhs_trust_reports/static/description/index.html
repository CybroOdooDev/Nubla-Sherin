NHS Trust Management

Reports & Documents

Adds the document and output layer on top of the Foundation and Operations modules.

Trust Profile PDF

NHS blue-branded QWeb PDF bound to the Trust form via the Print menu.

  • Header band (NHS blue #005EB8) with name, ODS code, FT badge, status
  • Section 1 — Identification (legal name, type, dates, Companies House)
  • Section 2 — Organisational Hierarchy (Region, ICB/ICS or Health Board)
  • Section 3 — Contact (address, phone, email, website)
  • Section 4 — Governance (Chair, CEO, MD, DoN, Finance Director + Board Members table)
  • Section 5 — Financials (budget, income, expenditure, surplus/deficit, capital, PFI)
  • Section 6 — Workforce & Capacity (FTE, beds, sites, departments)
  • Section 7 — Sites table (code, name, type, city, beds, A&E badge)
  • Section 8 — CQC Inspection History table (England only)
  • Footer with generation timestamp

Trust Directory Excel Export

Wizard accessible via NHS Trusts → Reports → Export Trust Directory.

  • 23-column NHS Trust directory with NHS-blue header row
  • Auto-filter enabled; top row + first 2 columns frozen
  • Surplus/Deficit colour-coded green (surplus) / red (deficit)
  • Filters: Health System, Status, Regions

Prerequisites

Requires odoo_nhs_trust_management and odoo_nhs_trust_operations. Also requires xlsxwriter: pip install xlsxwriter
