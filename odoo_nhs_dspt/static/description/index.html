NHS DSPT Compliance

Manage the annual NHS Data Security and Protection Toolkit (DSPT) self-assessment — assertions, evidence, ownership, gaps, improvement plans and submission — for NHS organisations and every supplier handling NHS data.

Standalone — no other NHS module required Versioned to the annual DSPT edition For Trusts, GPs, Care Providers & Suppliers
What it does

Versioned DSPT Framework

Standards, assertions and evidence items held as configurable data keyed by edition/year — so next year's DSPT revision is a data change, not a rebuild.

Organisation-Type Profiles

Trust, GP Practice, Care Provider, Supplier/Partner — each sees only the assertions and evidence applicable to their organisation type.

Ownership & Distributed Completion

Every assertion and evidence item is assigned to a responsible owner, with a "My Items" workspace for staff who only own a handful of items.

Evidence & Stale Tracking

Attach supporting documents to each evidence item, with a review date and an automatic stale flag once it needs refreshing.

Gap-to-Action

Any unmet mandatory item is a gap. Raise an improvement action with an owner, priority and target date to build the improvement plan.

Readiness Dashboard

Overall readiness %, gaps outstanding, overdue actions, stale evidence and a deadline RAG status, all in one view.

The annual cycle
Draft → In Progress (generate lines, carry forward last year, complete evidence) → Ready (readiness computed) → Published (snapshot & lock) → Submitted (recorded with the NHS DSPT portal reference)
Reports

DSPT Status (PDF)

Overall status, readiness by standard, and outstanding mandatory items — for the board or SIRO.

Improvement Plan (PDF)

Assurance Summary (PDF)

Frequently Asked Questions

Does this module submit the DSPT for me?

No. It prepares and manages the assessment — gathering evidence, assigning owners, tracking gaps and readiness. The official submission is still made through NHS England's DSPT portal; this module records the resulting reference and date.

Does it depend on the other NHS Odoo modules?

No. It depends only on base and mail, so it installs and works standalone — including for suppliers who have none of the other NHS modules. Where other suite modules are present, evidence can optionally reference them.

What happens when NHS England revises the DSPT next year?

Clone the current edition to a new year, adjust the standards/assertions/evidence that changed (each copy is flagged "New" for review), and next year's assessments follow the new shape automatically — no code changes required.

Can a published assessment still be edited?

No. Publishing snapshots and locks the assessment. A DSPT manager can explicitly re-open it, which is logged on the record's history.

Note: the seed DSPT edition included with this module is a representative starting framework aligned to the ten National Data Guardian data-security standards — it is not a verbatim copy of the full current NHS England DSPT question set. Review and adjust it against the toolkit published for the year you are actually submitting.
