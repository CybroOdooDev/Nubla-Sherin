Frequently Asked Questions

What is the difference between a PALS concern and a formal complaint?

A PALS concern is an informal, quick-resolution enquiry, while a formal complaint follows the statutory NHS complaints process with acknowledgement and response deadlines. A PALS concern can be escalated to a formal complaint at any time using the Escalate to Complaint action, which allocates a new COMP reference while keeping the original PALS reference for traceability.

Can patients and relatives submit complaints without logging into Odoo?

Yes. When the public complaint submission form is enabled in Settings, a secure token-protected link can be shared publicly. Patients or relatives can submit a PALS concern or formal complaint, optionally remain anonymous for PALS concerns, and receive an immediate reference number confirmation.

How are statutory response deadlines calculated?

Each complaint is assigned a Response Timescale preset — for example, Simple (25 working days) — either by default or per case. The acknowledgement and response deadlines are calculated automatically and can be tracked, and agreed with the complainant, from the Deadlines tab on the complaint record.
