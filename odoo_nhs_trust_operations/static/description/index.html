NHS Trust Management

Operations & Compliance

This module extends NHS Trust Management — Foundation with the full operational and compliance picture of an NHS Trust.

Features

  • Sites — physical locations (hospitals, clinics, ambulance stations) with GPS, A&E type, bed capacity, operating theatres, and clinical specialties.
  • Departments — sub-units within sites with type (clinical/corporate/support/research), specialty, head of department, and staff count.
  • CQC Inspections — complete inspection history with all 5 KLOE ratings (Safe, Effective, Caring, Responsive, Well-Led) plus Overall. Calendar view for forward planning.
  • Financials — annual budget, income, expenditure, auto-computed surplus/deficit, capital CDEL, PFI obligations.
  • Workforce & Capacity — total FTE (manually maintained) and auto-summed bed capacity from all sites.
  • Clinical Specialties — configurable lookup table seeded with NHS Data Dictionary specialty codes.

Menu Additions

  • NHS Trusts → Operations (Trusts, Sites, Departments, Board Members)
  • NHS Trusts → Compliance (CQC Inspections, State Change Audit)
  • NHS Trusts → Configuration → Clinical Specialties

Prerequisites

Requires odoo_nhs_trust_management (Foundation module). Install that first.
