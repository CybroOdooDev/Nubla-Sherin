Frequently Asked Questions

What makes this module Community-first?

This module is built to run on Odoo COMMUNITY. Odoo's asset/depreciation module (account_asset) is an ENTERPRISE feature and is NOT available in Community. Because the suite is Community-first, this module does NOT depend on account_asset. Instead it defines its own LIGHT asset model directly on the device record — acquisition cost, expected life, replacement year and an indicative current value — enough for lifecycle and replacement planning without reproducing Enterprise's depreciation engine.

How does the safety-alert workflow work?

When an MHRA, CAS, or manufacturer safety alert is received, you record the alert with its reference, date, and affected make/model. The alert-match wizard automatically finds affected devices in your register and creates action lines for each device. You then track the required action (quarantine, modify, update, remove from use), evidence the response, and close the alert when all affected devices are actioned. The complete audit trail is preserved for CQC and MHRA inspection.

How is the indicative value calculated?

The indicative value is a simple straight-line calculation: acquisition cost × (remaining life / expected life), floored at 0. It is a display/planning figure only — there is no depreciation schedule, no journal, and no account_asset. This gives estates and finance a reasonable current-worth and replacement picture on Community without any Enterprise accounting. Formal, postable depreciation is the optional Enterprise bridge's job, not this module's.
