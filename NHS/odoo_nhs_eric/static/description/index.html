Frequently Asked Questions

How does the module handle annual ERIC changes?

The module uses a versioned data-set definition (sections, items, validation rules, source mappings) keyed by collection year. When NHS England revises the return, you clone the previous year’s definition, adjust the items that changed, and mark them as new/changed/removed. No code changes are required — the module stays current year after year.

Which data sources are used for auto‑population?

The module reads from the Estate Register (sites, buildings, GIA, age, tenure, backlog, condition) and Estates Compliance (statutory‑compliance status by discipline). A source resolver maps each ERIC item to the correct figure. Manual items (cost, soft‑FM, energy) are entered separately.

What happens when I finalise a return?

Finalisation snapshots all values, stamps the return with the finaliser and timestamp, and locks the return so no further edits are allowed. The snapshot preserves the exact values submitted, even if underlying estate data changes later. You can still export the return in the submission format.
