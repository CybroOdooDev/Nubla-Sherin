Frequently Asked Questions

❓ What compliance disciplines are covered?

The module pre-loads: Water safety (HTM 04-01), Fire (RRO/HTM 05), Electrical (HTM 06), Ventilation (HTM 03-01), Asbestos, Lifting/LOLER, Medical gas (HTM 02-01), Pressure systems, Gas, Lightning, Drainage, and Working at height.

Each discipline comes with its specific compliance types, default frequencies, and HTM/regulation references. You can enable/disable disciplines per organisation.

❓ What is the accountable-person model?

The HTM regime requires specific named individuals to be accountable for each discipline. The module models:

  • Duty Holder – ultimate legal duty (often Chief Executive)
  • Designated Person – board-level 'informed person'
  • Responsible Person (RP) – day-to-day management
  • Authorised Person (AP) – authorised to carry out/supervise work
  • Competent Person (CP) – carries out the actual work
  • Authorising Engineer (AE) – advises and audits

Assignments include authorisation expiry dates; lapses are flagged as compliance gaps.

❓ Can I generate compliance items in bulk?

Yes. The Bulk-Apply wizard lets you:

  • Pick a discipline (or set of compliance types)
  • Select a set of buildings/sites
  • Set a starting last-completed date (or leave blank to start as due now)
  • Preview the items before committing

This is perfect for onboarding an existing estate — e.g. apply the full fire schedule to all 12 buildings in one action.
